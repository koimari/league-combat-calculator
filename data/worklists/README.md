# data/worklists — quantified gap worklists (E-series)

Generated from the champion-audit swarm + wiki cache leveling analysis. Each
worklist feeds one swarm batch.

- `e2-dot-ticks.json` — 57 DoT/channel undercounts with exact implied tick
  counts (per-tick vs Total leveling rows). E.g. Nasus R 30x, Renekton R 30x,
  AurelionSol Q 26x, Fiddlesticks R 20x, Malzahar E 16x, Morgana W ~10x,
  Samira R 10x, MissFortune E 8x, Lucian R 22x.
- `e3-stacks.json` — 235 stack/charge/mark-system candidates (damage-relevant
  cores: Varus Blight, Twitch poison, Vel'Koz research, Tristana E, Nasus Q,
  Darius bleed, Brand Blaze, Braum Concussive, Cho'Gath Feast, Corki R...).
