# Scryglass Design Direction

## Visual anchor

The illustrated Summoner's Rift background is the product's charm and primary visual world. Preserve it at full color and recognizable contrast. Interface surfaces sit on top as restrained ivory paper and deep green proof panels; do not replace the landscape with a generic dark dashboard.

## Interaction character

Controls should feel deliberate and physical without becoming skeuomorphic decoration:

- Primary actions use deep green filled faces with a soft downward shadow.
- Secondary actions use raised ivory faces.
- Segmented selections sit in a recessed shared rail; only the selected segment rises.
- Steppers are compact raised keys with hover lift and pressed compression.
- Empty item slots are shallow inset wells, not dashed coupons.
- Text utilities remain flat so every action does not compete for attention.
- Motion is 150–210ms, state-driven, and removed under reduced motion.

## Champion entry

The empty champion state is one compact invitation. It must not render an empty statistics matrix or expose role/level controls before a champion exists. Desktop pairs a Rift-backed roster button with one heading and one sentence. Mobile keeps the same horizontal relationship rather than stacking a tall empty card.

## Hierarchy

1. Champion and current comparison result.
2. Build A/B and enemy roster.
3. Fight window.
4. Ability tuning, optimization, BIS, and proof.

## Accessibility

Controls retain visible focus, disabled explanations, 44px primary mobile targets, non-color selection cues, and reduced-motion equivalents.

## Typography

Manrope remains the sole interface family; system monospace is reserved for time, receipts, and measurements. Operational text uses a compact role scale rather than microprint: 12px metadata, 13px controls, 15px body copy, 16px card titles, and larger data/display roles. Dark proof surfaces raise secondary text contrast and leading instead of shrinking it. Ability names may wrap to two lines, and responsive layouts add columns/rows before truncating identity-critical labels.
