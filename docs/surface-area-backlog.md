closeout (rows `SC*`) and resolution (rows `SR*`) campaigns surfaced and did not close.
Delete a row when its fix lands; this file is the one home for the list. Traps live in
`CLAUDE.md` Known Quirks.

| ER5 | `src/calculator/` tail | The rule-5 lint scans the whole package; `tests/test_literal_defaults.py` partitions it into `ROOTS` (96 roots, 421 files) and `ER5_TAIL` (89 modules, about 1,279 sites). Twenty-two tail modules carried no cached-data literal and were moved across with no code change. Three producers now have named contracts read from their own stamps: `cast_event_row` (one producer, every field on every row, so all 21 reads went fail-closed), `damage_event_row` and `heal_event_row` (several producers each, so only the intersection may be required). `tests/test_row_stream_census.py` measures all nine published streams from the committed baseline every run and carries the DECISION RULE for converting a site: the key must be universal on that stream, the variable must certainly hold a row of it rather than a sentinel, the container itself must be guaranteed, the site must run AFTER publication because the census measures published rows, and the reader must be reached ONLY with engine output. `bis_objective` fails the last one: it is handed partial payloads and `bis.py` wraps the candidate loop in `except (KeyError, ValueError)`, which WITHHOLDS that build from ranking, so indexing there converts a scored candidate into a silently dropped one. Each clause was learned from a conversion that had to be undone, and the census asserts the pooling mistake directly so the reasoning cannot rot. Mechanising the first two clauses over the largest tail module found five loops on a censused stream and one site inside them, which clause four then disqualified: the mechanically provable set is small and the rest wants its author's intent rather than a scan. | Work the tail producer by producer against the census, never site by site, and expect most of what remains to be defaults that are CORRECT. A site failing any clause keeps its default, which is then not debt. The method's own boundary: it licenses reads of PUBLISHED rows, because `golden_coupled_baseline.json` is a committed corpus a test re-derives. Internal rows have none, the pair baseline holding aggregates rather than event rows, so serializers like `public_response` (50 sites) cannot be licensed until a corpus for the internal shapes is captured and gated, which is its own slice. |
